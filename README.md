# Projeto Cordel

Página web em HTML e CSS sobre o Cordel de Milton Duarte.

## Conteúdo

- `index.html`: estrutura da página
- `style.css`: estilos
- `imagens/`: recursos visuais
- `cordel-moderno.txt`: texto-fonte do cordel

## Tecnologias

HTML e CSS

## Como executar

Clone o repositório e abra o arquivo `index.html` no navegador.
